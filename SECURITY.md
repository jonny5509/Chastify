# Security Policy

## Supported Versions

Security fixes are generally provided for the latest released version of this integration.

| Version | Supported |
| --- | --- |
| 1.3.x | Yes |
| < 1.3 | No |

If you are unsure whether a version is supported, please update to the latest release before reporting an issue.

## Reporting a Vulnerability

Please **do not report security vulnerabilities through public GitHub issues**.

If GitHub's private vulnerability reporting is enabled for this repository, use the **Report a vulnerability** option in the repository's Security/Advisories area.

If private vulnerability reporting is not available, open a GitHub issue requesting a private security contact **without including vulnerability details, credentials, tokens, or other sensitive information**. The maintainer can then provide a suitable private reporting channel.

When reporting a vulnerability, please include, where possible:

- A clear description of the vulnerability
- Affected versions
- Steps to reproduce
- Potential impact
- Relevant logs or proof of concept, with secrets and personal information removed
- Any suggested mitigation or fix

Please allow maintainers reasonable time to investigate and prepare a fix before publicly disclosing the vulnerability.

## Disclosure Process

We follow a coordinated disclosure approach where practical:

1. The report is acknowledged and reviewed privately.
2. The issue is reproduced and its impact assessed.
3. A fix or mitigation is developed and tested.
4. A patched release is published where appropriate.
5. Relevant users are informed of the vulnerability and recommended update.

Security advisories may be used to privately coordinate fixes and later publish vulnerability information when appropriate.

## Security Best Practices

Please do not include the following in issues, pull requests, logs, screenshots, or other public project content:

- API keys or access tokens
- Passwords or authentication credentials
- Home Assistant secrets
- Personal information
- Private URLs or other sensitive configuration

Thank you for helping keep the project and its users secure.

## Policy Updates

This policy may be updated as the project's security practices and supported versions change.
